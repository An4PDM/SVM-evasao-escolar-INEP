# SVM-evasao-escolar-INEP
O objetivo deste projeto de ML é  utilizar características das escolas presentes nos microdados do INEP de 2025 para identificar aquelas que apresentam taxa de abandono no Ensino Fundamental. O projeto envolve análise exploratória dos dados, tratamento e preparação de variáveis, aplicação de One-Hot Encoding e treinamento de um modelo Linear SVM.
